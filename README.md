Create daily GPX, KML files for use with [Organic Maps][0] or [OsmAnd][1] from open gas prices data.

For France, the data are coming from [prix-carburant-economie.gouv.fr][2].
These data are open source, see the [FAQ here][3].

For Italy all code is copied from [Gh0stz0x][4] fork of original repo.

To keep the file updated on your android device you can try [HTTP Shortcuts][5].

Scripts to execute are named after the country they are handling the data from.

 [0]: https://organicmaps.app 
 [1]: https://osmand.net/
 [2]: http://www.prix-carburants.economie.gouv.fr/
 [3]: https://www.data.gouv.fr/fr/faq/
 [4]: https://github.com/Gh0stz0x/gas-price
 [5]: https://http-shortcuts.rmy.ch/
